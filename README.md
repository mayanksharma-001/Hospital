# District Government Hospital Website (Informational)

React + Vite informational website for District Government Hospital, Churu, Rajasthan.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run lint
```

## Configuration

Update `/src/config/siteConfig.js`:

- `APPOINTMENT_URL` (external official portal URL)
- Hospital coordinates and contact details
